# Сайт Князевой Елизаветы Сергеевны — repository-ready v2

Статический сайт без сборщика: можно вручную загрузить все файлы в репозиторий и сразу открыть через GitHub Pages, Cloudflare Pages или любой статический хостинг.

## Локальный запуск

```bash
python -m http.server 8000
```

Открыть: `http://localhost:8000`

## Ручная загрузка в GitHub

1. Создайте пустой репозиторий.
2. Нажмите **Add file → Upload files**.
3. Перетащите **содержимое папки**, а не сам ZIP.
4. Подтвердите Commit changes.
5. Для GitHub Pages: Settings → Pages → Deploy from branch → main / root.

## Перед публикацией

- заменить `https://example.ru/` во всех SEO-файлах на реальный домен;
- добавить фотографию;
- заполнить телефон, MAX и email;
- подключить реальную отправку формы;
- утвердить договор и политику;
- проверить цены.
